設計概念 — AI Mic

白→薄荷漸層的麥克風，加一枚 AI 火花，坐在中亮度紫磚上。麥克風是「語音輸入」最通用、不必解釋的符號；火花是生成式 AI 的通用訊號；紫色沿用品牌 violet（即 App 的 inject／AI 處理 狀態色），字符底部的薄荷漸層保留品牌 teal。整個圖示只有 3 個形狀，縮到 16 px 仍是同一個剪影。

16 px 可讀性推理

設計時以 16 px 為第一檢驗尺寸：先看縮到 16 px 還剩什麼，再回頭決定 256 px 的細節。五條規則：
  1. 剪影先於細節。只留 3 個形狀；把圖示糊掉（squint test）仍能認出「麥克風」。大尺寸才多出來的細節（漸層、火花）都不承擔辨識。
  2. 筆劃 ≥ 2 px、間隙 ≥ 1 px。256 母版上筆劃 32、間隙 16，正好是 16 px 的 2 px 與 1 px；沒有任何低於 2/16 畫布的細線。
  3. 對齊像素格。邊緣都落在 16 單位格線上（16 px 時 = 整像素，32 px 時 = 2 px），膠囊寬 4 px 而非 4.5 px；托架用方正 U 形（直邊＋小圓角），直邊在縮圖時不會變成半透明的灰邊。
  4. 明度承擔對比。磚面落在中亮度帶，白色字符與它的對比 3.9–5.2 : 1；邊界對深／淺工作列都 ≥ 3 : 1（見下表）。
  5. 顏色只加分。薄荷漸層與火花的色相是品牌感；就算只看灰階，磚與字符的明暗差仍在。

交付與產生流程

SVG 是單一事實來源；PNG／ICO／ICNS 皆由它衍生，不手改。
app-tauri/src-tauri/icons/icon.svg     # App 圖示母版（256，滿版方形）
app-tauri/src-tauri/icons/tray.svg     # 系統匣／選單列字符母版（32 格線，單色）
scripts/gen-icons.mjs                  # 把兩個母版轉成 PNG／ICO（sharp + png-to-ico）

npm run icons                          # gen-icons.mjs → tauri icon（icns / ico / 各尺寸）
  ├─ 32x32 / 128x128 / 128x128@2x / 16·24·48·64·512 .png, icon.ico, icon.icns   (from icon.svg)
  └─ tray-16 / tray-22 / tray-32 / tray-44 .png                                  (from tray.svg)

app-tauri/src-tauri/src/lib.rs         # build_tray：include_bytes!("../icons/tray-32.png")
                                       #   + .icon_as_template(cfg!(target_os = "macos"))
